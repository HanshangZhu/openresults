G1 动作段判定器 — LLM-judge 线:从 VQ 码字到连续潜向量的四臂阶梯与三场景对照

阶段报告,续接标签审计后全类现状盘点。 记录 2026-08-25 单日内 LLM-judge 线(预训练语言模型 + 1600 条人工标注 → 会说理由的动作段判定器)的完整实验链与结论。

Conclusion

  • 预注册判据 PASS(第四臂):Qwen-1.5B + 连续潜向量 + 加码 SFT(v2)在 8 张金标卷上 4 类达到现役窗级 MLP 的 90%(判据线 ≥3 类),其中 clap 0.909 / handshake 0.844 直接反超 MLP——LLM 臂首次在任何类上超过现役判定器,并附带真实的 CoT 说理(区间+病因)。
  • 单变量归因成立:四臂阶梯(T5+VQ 55% → Qwen+VQ 73% → 连续潜向量 87% → 加码 94%, 数字为 8 类"达 MLP 百分比"均值)中,最大的一跳来自动作表示(VQ 码字→连续潜向量, 与 MLP 同款编码器),证实此前判定的"瓶颈在感知不在语言"。
  • RL 阶段(GRPO/GSPO)在当前数据规模下无信号:SFT 已把全部 1128 条训练判定连同区间 文本背熟,verdict 与区间 IoU 奖励在训练集上双双饱和,组优势恒零——RLVR 需要"未背过" 的标注池;半量切分重训实验(SFT/RL 各半)进行中,结果另行补报。
  • 40 段全新盲评(user 全判):MLP 最有信心的 pass 侧真实纯度 0.875(6 类 5/5 全对, kick 仅 1/5);LLM verdict 命中 0.700、pass 侧纯度 0.926,且抓住了 MLP 放走的 4 条脏 kick 中的 3 条——两judge失误几乎不重叠。

Analysis

  • 测量:表示假设成立——同一编码器的连续令牌换掉 VQ 码字,8 类中 6 类上涨、均值比 +14pp;语言侧(CoT 说对区间与病因)在第四臂已明显可用,但对全新段仍有套用训练话术的 幻觉,理由文本只可参考、以视频为准。
  • 测量:RL 无信号的机制是可验证奖励被 SFT 记忆吞尽——1128 条的 verdict 与区间文本 均为训练目标;GSPO/GRPO 之别不改变此结构。半量切分(SFT/RL 条目零交叠各 ~564)实验 进行中,待补报。
  • user 判断(2026-08-25):LLM 上限更高。支撑证据:开箱均衡性(金标 R 0.626 vs 0.168)、与 MLP 失误不重叠(kick 否决价值已在盲评实证)、可扩杠杆未用尽(更大基座、 未背过的新标注作 RL 燃料、混合判官);反向证据:逐类调档后 MLP 仍在 4 类领先、LLM 校准两极化无操作点。此判断标注为方向性决策,非已证结论。
  • next(user 已定向):半量切分 GSPO 出结果补报;新增标注(盲评 40 判定已落库、Nolan 复审进行中)作为未记忆 RL 燃料的天然来源。

G1-MotionGPT 线大总结:十条经验规律(2026-08-29)

背景一句话:我们在清洗一个人形机器人(Unitree G1)动作数据集,把预训练语言模型改造成 "动作段审查员"——读一段动作,判干净/脏,并写出问题区间与病因。本文总结这条线 (2026-08 下旬密集战役)沉淀出的十条经验规律,每条给证据数字和适用边界。

Problem and terminology

研究问题:把小型预训练语言模型改造成动作段审查员,哪些设计选择真正影响判定质量, 哪些直觉在受控实验下不成立。

管线形态(读懂规律所需的最小背景)

  • 动作编码前端:动作序列(关节角/速度/连杆位置,20Hz)→ 编码器(conv-AE 512 维,或 HumanoidBERT 双向注意力 1536 维)→ 每 0.2 秒一个连续向量。
  • stage-A(动作-语言预训练):把动作向量当"词"插进 Qwen2.5-1.5B 的输入流,在 155k 段动作描述/定位任务(BONES-SEED + BABEL)上训练,LLM 学会"读动作"。
  • stage-B(判定微调):在 2,437 段人工 pass/fail(fail 带区间+病因文本)上 LoRA 微调, LLM 学会"判动作"。评测 = 370 段 held-out(按源 entry 分组防泄漏)verdict AUC。
  • 生产版:stage-B v2(fail 标签文本经改写重训),val AUC 0.888,90% 判脏准度下自动 剔除约六成脏段。

十条规律

1. 语言能力与动作判定在 1.5B 里抢地盘,没有配置两头兼得

  • 完整前沿:LoRA r32(判定 0.889 / MMLU 0.471,破守门线)↔ 全参(0.839 / 0.564)↔ 全参+KL(0.818 / 0.575)。判定每涨一档,语言掉一档,反之亦然。
  • 容量归因证据:文本锚配比 0.15→0.50 对 LoRA 的 MMLU 无效(0.48-0.50 平坦),换全参立刻 +5pp——语言保持是容量问题,不是数据配比问题。
  • 边界:仅在 ~1.5-4B 小模型上验证;判定器当纯打分器用时语言破线无实际伤害。

2. LoRA 不只是够用,是最优;约束越松判定越好

  • 同前端同数据同学习率(1e-5)下终分单调:r32(0.883)> r128(0.861)> 全参(0.839)> 全参+KL(0.818)。
  • 反直觉的一半:KL 与全参保住了冻结特征(全参+KL 的探针比全参高 2.9pp)却降低了 微调终分——约束保护表征几何,同时降低可塑性(与规律 7 同源)。
  • 边界:结论属于"2.4k 样本判定微调"这个数据规模;数据大一个量级后是否仍单调未测。

3. HumanoidBERT 双向前端条件性有用,前端与学习率有交互

  • 统一 1e-5 下 HBERT 压 conv-AE:r32 臂 +2.1pp(0.883 vs 0.862),r128 臂打平 (0.861 vs 0.864);而在 1e-4 与全参配方下前端无增益(stage-A 四读数逐位持平)。
  • 反例记录:HBERT v1(逐关节 token + 自蒸馏)训练后低于自身随机初始化(0.720 < 0.746), 自蒸馏在此配置下表征塌缩,放大方向关账。
  • 边界:+2.1pp 在单切分噪声(±2.5pp)门槛边上,"方向性支持"而非坐实;需第二切分。

4. 针对 BABEL/BONES 大幅动作预训练(stage-A)有特征层证据,终分级对照缺失

  • 特征层:stage-A 把判裁相关内部特征抬进 0.79 档(30k→60k 递进),六个进入 stage-B 的 底座全部带 stage-A。
  • 诚实标注:"无 stage-A 直接 stage-B"的对照从未跑过(动作投影层由 stage-A 训练, 跳过它需改协议),该规律在终分层面待补对照。

5. 段内信息天花板约 0.80:换表征已榨干,剩余误差不在特征里

  • 五种模态/架构冻结特征在同一张 442 段 kick 考卷上收敛:HBERT 0.773、DiT 0.780、 282M 预训练动作模型 0.774、纯像素 V-JEPA2(从未见过关节角)0.774、stage-A Qwen 0.791。
  • 三连探针关线:显式加速度/jerk 标量(最高 0.61)、段外结构+边界几何(最高 0.64)、 视觉先验(0.774,融合零增量)。
  • 推论:剩余误差住在语义判断与标签噪声里;标签噪声底(同段盲判自一致率)是整条线上限的 最便宜测量,尚未执行。

6. 冻结特征与零样本行为之间有巨大"兑现缺口",判定微调是收账动作

  • 同一模型:冻结特征线性可读 0.79,零样本嘴上判定只有 0.58;stage-B 微调后 0.889—— 信息在,通道原本没打通。
  • 兑现最大的地方是语义类:punch/wave 在任何冻结特征头上都 ~0.55(死类),判定微调后 0.82-0.89——靠"标称动作 × 实际动作比对"这一冻结特征头拿不到的语义通道。
  • 长期最弱类是 kick(0.78-0.80):病因在细粒度运动学,LLM 通道反而丢精度。

7. 特征质量与可微调性是两个量,探针不能当选型器

  • mid 层探针预测 stage-B 终分的"同序律"曾 4/4 全中,扩到 8 臂后 Spearman 相关 −0.62 (预测第一的臂终分垫底)——小样本巧合,已打 SUPERSEDED。
  • 机制解释与规律 2 的 KL 现象同源:约束提高冻结特征质量、降低微调可塑性,两者解耦。

8. 换底座六战六败,且"别处越聪明,判定越差"

  • 统一训法下:Qwen2.5-1.5B(0.883)> Qwen3-1.7B(0.831)≈ Qwen3.5-2B(0.829,22k 步 参考臂)> R1-Distill(0.816)> Phi-4-mini-3.8B(0.779,参数最大、推理基准最亮、垫底)。
  • 推理蒸馏系包揽倒数三名;参数量假设同场阵亡(2.5 倍参数反退 10pp)。
  • 机制假设(待验证):思考型输出习惯与简短判词格式冲突。

9. 别让它想,别听它说:思考与对话在小判定器上是负资产

  • 测试时思维链:先分析再判,AUC 从 0.889 跌到 0.669——训练里病因文本只跟在 fail 后面, 任何分析样文本都拉高判脏倾向,且被迫思考时会在干净段上编造缺陷。
  • 小规模 GRPO(每类 20 段):3 分钟收敛为"跳过思考直接给判词"(奖励无思考项,最短路径 拿满),链条件 AUC 仅回到 0.700。
  • 纠错对话:真纠正改口 20/20,被冤枉也改口 17/20——85% 是无条件服从。用法结论: 判定器当打分器(读 P(fail)),人的纠正直接落库,不经模型确认。

10. 病因文本是双刃剑:密集监督救语义类,风格耦合毒化判决与判词

  • 正面:1,147 条"区间+病因"文本是 stage-B 的密集监督,是语义类被救活的原料之一。
  • 反面之一:病因文本与 fail 标签风格耦合(见规律 9 的思维链病理)。
  • 反面之二:模型逐字继承标注速记的口癖与元评论(输出过"模型应该判脏"这类标注者旁注)。
  • 修法已验证:1,147 条标签重述(区间数字逐字保留、删元评论)后重训,AUC 0.8886→0.8883 零代价,判词风格病灶清零;原标注永久保留于独立 sidecar。

生产状态与开放问题

  • 生产判定器 = stage-B v2(改写标签版):val AUC 0.888 / acc@0.5 0.811 / 90% 准度剔脏 recall ≈ 0.6;已接入抽查前端。
  • 开放:①标签噪声底盲判(上限测量);②三个 ~0.88 配方需第二切分分序;③规律 4 的 无 stage-A 对照;④kick 类的人工保留策略。

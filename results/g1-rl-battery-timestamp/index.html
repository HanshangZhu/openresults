G1 判定器 RL 算法电池与时间戳注入 — 一夜七实验的整合结论

背景一句话:语言模型判定器(动作连续向量 + Qwen2.5-1.5B)上,我们用同一份数据、同一个 奖励、同一个起点,对五种强化学习算法做了受控对比,并验证了"输入端时间戳注入"这一格式 改动;所有实验为 user 会话内逐项确认后执行。

Conclusion

  • 时间戳注入是本夜最大的单点收益:动作序列每 1 秒插一个文本时间标签(零新参数), 仅此一项就把脏区间定位重叠度从 0.515 提到 0.609,追平"训练数据翻倍"的效果;该格式 已按 user 裁定烤入集群大规模预训练。
  • 算法排序(3 seeds 确认头尾):GSPO 0.664±0.008 > GRPO 0.636 > 无RL基线 0.625 ≈ PPO 0.624 > SAO 0.601 > DAPO 0.595±0.010。GSPO 对 GRPO、对基线的优势均超出种子方差 数倍——"GSPO 比 GRPO 好"在本设置成立;critic 类算法(PPO/SAO)在小预算下因价值 估计学不准而无增益;DAPO 因去掉 KL 锚在 400 步内漂移垫底。
  • 定位天花板与算法无关:七个模型的定位重叠度全部落在 0.55-0.63;标注端点抖动模拟 显示 ±0.3~0.5 秒的人工模糊下完美定位器也只能得 0.58-0.67——现有考卷已量不出更好的 定位,改进方向是换合成拼接考卷,不是换算法。
  • 奖励设计是判定侧的真瓶颈:7/8 个类"闭眼全判脏"的期望奖励高于诚实判别(kick 基率 80% 时 0.84 对 0.20),所有 RL 臂在弱类上一致学会弃疗;唯一基率平衡的 handshake (47%)恰是 RL 唯一干净起飞的类(纯度 0.9-1.0)。类平衡奖励是下一轮的首要修改。

Method

五臂共同点:起点 half-TS、RL 数据 565 条(模型未逐字见过)、每步 32 条序列、400 步、 温度 1.4、lr 1e-6。差异仅在算法机制:

GSPO 组内均值/方差 序列级 ±0.1 0.02 4 组×8

电池 spec、TS-GSPO spec、裁剪增广 spec 均为 user 会话内原文确认("再加一个GRPO VS GSPO VS PPO VS DAPO VS SAO 对照实验"/"先挂上TS-GSPO"/三 spec 回贴确认)。偏离记录:GSPO 序列 级裁剪 ±0.1 为实现选择(论文用更小范围);SAO 异步机制单卡不可复现,记 N/A;GSPO 补种子 首跑死于奖励解析边角(生成文本以 VERDICT: 结尾),修复后重跑。首夜另有两项负结果:随机 裁窗增广 0.563(合成 pass 文本淹没)、投影 warmup 课程 0.551、prediction 混料 0.576, 均单 seed。首尾残留抢救(user 原始设计,140 条过 MLP 静音门)0.630,小胜基线。

Analysis

  • 测量结论:序列级比率(GSPO)在短输出、小 LoRA 设置下优于 token 级(GRPO),且组相对 优势优于弱 critic;KL 锚在 400 步小预算内是稳定器(DAPO 去 KL 即漂移)。
  • 测量结论:时间定位的改进空间已被考卷测量精度封顶;判定的改进空间被奖励结构封顶—— 两个瓶颈都不在模型容量,这与"规模预训练前先修后训练方法"的 user 判断一致。

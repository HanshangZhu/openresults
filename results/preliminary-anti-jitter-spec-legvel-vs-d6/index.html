Preliminary report：walk / kick 抗抖（相对 D6 GTrXL）

Status: preliminary · Date: 2026-07-24
对照报告： D6 GTrXL（MoE UniLab distill）

D6 GTrXL 学生在 locomotion 上 BeyondMimic 成功率很高，但 walk / kick 的物理执行仍明显抖动。本报告记录一次仅调整奖励、重训 kick 与 walk 专家的实验，并报告高频抖动是否下降。

1. Conclusion

  • Kick： 代表性视频上判定为可用（双方审阅后的共识）。
  • Walk： 尚未接受。 抖动指标已改善，但起步相对参考与 SONIC 仍偏弱；是否过关待定。
  • 抖动证据： 相对 D6 时期锁定的 kick / walk 专家（OldSpec），hf_v_ratio 中位数由 walk 8.04 → 2.41、kick 6.20 → 3.61（越低越平滑）。两动作 BeyondMimic SR 仍为 1.0（val；walk (n=18)，kick (n=14)）。

hf_v_ratio 表示执行轨迹相对同 clip 参考动作的高频关节速度能量比，是「抖动减轻」的定量依据。BM SR 只反映能否跟完整段，不度量平滑程度。

2. Method

  1. 在全部训练集上，用下文加强后的奖励从零训练一台单策略（约 5000 iterations）。
  2. 约在 2500 iteration 处分出 kick、walk 两个专家，各再训练 2500 iterations（终点约 4999）。
  3. 不从 D6 权重继续训练。D6 仅作为同 clip 的视频对照（实体 = 策略，蓝色半透明 = 参考动作）。

3. 相对 D6 时期的奖励改动

D6 的老师沿用当时默认跟踪奖励：动作变化惩罚较弱，且无关节速度跟踪。本次主要改动如下。

奖励项 D6 时期默认 / OldSpec 本次
动作变化惩罚 action_rate_l2 −0.1 −1.0
全身关节速度跟踪 motion_joint_vel 0 单策略阶段为 1.0；专家阶段为 0
腿部关节速度跟踪 motion_joint_vel_leg（髋、膝、踝；12 DoF） 无 专家阶段 2.0（新增）

仿真环境、action_scale 与 BeyondMimic 终止条件与 D6 报告一致（UniLab–MuJoCo PPO）。

5. Remarks

  • 加强动作变化惩罚并加入腿部速度跟踪后，本 val 切片上 hf_v_ratio 明显下降，BM SR 保持为 1.0。
  • 视觉结论：kick 可用；walk 待确认（起步相对 SONIC）。
  • 本报告不涵盖：将新专家再蒸馏为 D6 角色的单学生，或以本 tip 替换 MoE 报告中的 D6。

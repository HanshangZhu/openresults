Preliminary report：walk / kick 抗抖（相对 D6 GTrXL）

Status: preliminary · Date: 2026-07-24
对照报告： D6 GTrXL（MoE UniLab distill）
Results profile: training-physical

D6 GTrXL 学生在 locomotion 上 BeyondMimic 成功率很高，但 walk / kick 的物理执行仍明显抖动。本报告记录一次仅调整奖励、重训 kick 与 walk 专家的实验，并报告高频抖动是否下降。

1. Conclusion

  • Kick：未通过外部审阅（2026-07-24 晚）：脚部（踝/足端）仍有可见抖动。此前「可用」的初判被推翻。
  • Walk：未通过。 主抖动指标已下降，但 gait initiation（起步）相对参考与 SONIC 仍明显偏弱。
  • 抖动证据（数字结论不变）： 相对 D6 时期锁定的 kick / walk 专家（OldSpec），主指标 hf_v_ratio 中位数（↓）由 walk 8.04 → 2.41、kick 6.20 → 3.61。两动作 BeyondMimic SR 仍为 1.0（val；walk (n=18)，kick (n=14)）。
  • 判定： hf_v_ratio 的改善不足以通过视觉验收；两动作均需进一步迭代。

2. Problem and terminology

研究问题：在与 D6 报告相同的跟踪合同下，加强动作平滑与腿部速度跟踪后，kick / walk 专家的高频抖动是否下降，以及视觉上是否可接受。

3. Method

  1. 在全部训练集上，用下文加强后的奖励从零训练一台单策略（约 5000 iterations）。
  2. 约在 2500 iteration 处分出 kick、walk 两个专家，各再训练 2500 iterations（终点约 4999）。
  3. 不从 D6 权重继续训练。D6 仅作同 clip 视频对照。

5. Analysis

  • Finding: 本 val 切片上，hf_v_ratio 相对 OldSpec 明显下降，BM SR 保持 1.0（主表）。
  • External review（2026-07-24 晚，已记录）: kick 脚部（踝/足端）仍有可见抖动；walk 的 gait initiation 起步问题仍在。两动作视觉验收均未通过。
  • Per-joint 定位（探针已落盘）: 本 tip 上关节速度误差 (|\Delta\dot q|) 仍以膝、踝最大——kick 前四名为左/右膝（约 1.24 rad/s）与左/右踝 pitch（约 1.13–1.16 rad/s）；walk 前二名即左右踝 pitch（约 1.15 rad/s）。相对基线（g_jvel_ar@4999）各腿部组均有下降，但足端误差仍是最高带，与外部审阅「脚仍抖」一致。证据：outputs/plan1_bm_ppo_spec_g2500_ar_legvel/per_joint_err_tip4999/。
  • Not shown / next: 不以本 tip 替换 MoE 报告中的 D6；下一步设计（足端抖动与起步跟踪）待 Run Spec 确认。
Appendix：算式与实现 
v = diff(joint_pos) * 50          # rad/s, all DoF
frac(traj) = power in [8,25] Hz / total FFT power   # band_power_frac
hf_v_ratio(clip) = frac(exec) / max(frac(ref), 1e-8)
report value = median over val clips

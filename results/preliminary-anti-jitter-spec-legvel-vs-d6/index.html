  • Decision: 本页只作 preliminary 对照与续训说明；是否改 D6 / 再开 DAgger / 改 walk 起步合同 — 待用户确认，不在此结案。

5. Analysis

  • Finding: 续训支线在 walk/kick val 上把 BM 拉回 1.0，并把 hf_v 压到明显低于 OldSpec（主表）；路径是 冷启 G_jvel_ar → @2500 Spec fork + leg-vel，不是从 D6 FT。
  • Working interpretation（user 确认视觉）: kick 跟踪已接近可用；walk 起步仍弱于 SONIC——参考早期几乎不迈步时，SONIC 跟着不迈，Expert 仍会抢步。数字抗抖与起步相位是两件尺。
  • Unknown / 待验证: Spec_legvel 蒸馏成学生后能否在宏 SR 上贴齐 D6，同时保住 hf_v；walk 起步是否要单独合同（initiation window）。
  • Next: 保持 preliminary；是否以本 Expert 替换 MoE locked walk/kick teacher、或开新 DAgger — 等用户拍板。

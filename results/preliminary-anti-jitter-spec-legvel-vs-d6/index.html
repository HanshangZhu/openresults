Preliminary：walk / kick 抗抖（相对 D6）

PRELIMINARY · 2026-07-24 · 对齐对照：D6 GTrXL 报告

D6 那版 walk/kick 能跑完，但动作抖。这次只改训练奖励，重训 kick / walk 两个专家，看抖能不能压下去。

1. Conclusion

  • Kick：可用（你我共识，看视频）。
  • Walk：待确认（数字抗抖有改善；起步两步肉眼仍不如 SONIC，是否过关未定）。
  • 支持「jitter 改善」的数字：相对 D6 线用的旧 kick/walk 专家（OldSpec），执行相对参考动作的高频速度比 hf_v_ratio 中位数——walk 8.04 → 2.41，kick 6.20 → 3.61（越小越不抖）。两者 BeyondMimic SR 仍为 1.0。

2. 这次怎么训的

  1. 先在全部训练数据上，用加重后的奖励从零训一台单策略（约 5000 iter）。
  2. 从中间检查点（约 2500 iter）分出 kick、walk 两个专家，各再训 2500 iter（终点约 4999）。
  3. 没有接着 D6 的权重训；D6 只作视频对照（同 clip、蓝鬼 = 参考动作）。

3. 相对 D6 那一版，reward 改了什么

D6 的老师来自当时默认跟踪奖励（关节速度跟踪基本关着，动作变化惩罚很弱）。这次针对抖，主要改了：

奖励项 D6 那一版（旧默认 / 旧专家） 这次
动作变化惩罚 action_rate_l2 −0.1 −1.0（加重，少抖指令）
全身关节速度跟踪 motion_joint_vel 0 单策略阶段曾开到 1.0；专家阶段 关掉（0）
腿关节速度跟踪 motion_joint_vel_leg（髋膝踝 12 维） 无 专家阶段 +2.0（新增）

其余环境与评测合同与 D6 报告一致（UniLab–MuJoCo PPO、BeyondMimic terminate 等）。

5. Analysis

  • Finding: 加重动作变化惩罚 + 腿速度跟踪后，walk/kick 的 hf_v 相对旧专家明显下降，SR 仍满。
  • 共识: kick 肉眼可用；walk 抗抖数字好了，起步是否过关 待确认。
  • Not shown: 还没把新专家重新蒸馏成像 D6 那样的单学生；也没说要替换 D6。
  • Next: 等 walk 视觉拍板后再定是否续做蒸馏 / 改起步。

UniLab PPO tracker 与 VAD_Cleaned_50Hz_Rollouts_V2 构建

Date/scale: 2026-07-23 / tracker train 1113 · filter 1384/1392 · semantic K=8
Output profile: markdown-project-report（HTML 同目录）
Results profile: training-physical + dataset-verifier
Verdict: PASS

本报告先交代 UniLab–MuJoCo PPO tracker 的训练数据、num_envs=4096 流程与最终 BeyondMimic success rate；再说明如何用该 tracker 产出与 V1 对应的 VAD_Cleaned_50Hz_Rollouts_V2（50Hz 过滤执行态集）。Tracker 细节见 2026-07-23-MOE-unilab-specialist-distill-report.md（未随本公开包发布）。

1. Conclusion

PASS。

  • Decisive evidence: tracker 学生 D6 GTrXL test BM SR 0.993（single-policy baseline 0.960）；用其过滤得到 VAD_Cleaned_50Hz_Rollouts_V2 接受 1384/1392（99.4%）（§4）。
  • Counter-signal: 过滤仍拒 8 条（terminate / 未跑完）；reject live 视频已覆盖全集。Accepted 的 walk / kick 相对 reference 普遍存在高频关节颤振（§4.5），上肢动作则明显更稳。
  • Not shown: 可部署动作 router；GTrXL 相对 MLP 的容量优势（MoE 报告标 无证据）；本 filter 尚未用 Tracking MPJPE / EE / jerk 二次卡控（MPJPE 仅审计）。
  • Decision: 下游先用 VAD_Cleaned_50Hz_Rollouts_V2 时须知 locomotion 平滑度未门控；进一步工作见 §5（MPJPE/EE/jerk 加严；与 SONIC 同协议对照）。

4.5 Observation — accepted walk / kick 高频抖动

外部审阅（locomotion 为主）指出：accepted overlay 上 walk / kick 抖得明显，上肢动作则较好。对本集全部 accepted walk 186 + kick 134 条，相对同 clip 的 50Hz reference 计算关节轨迹的加速度 / jerk RMS 比（exec / ref；50Hz 差分）：

动作 n（accepted） jerk 比中位 accel 比中位 j≤1.5 且 a≤1.5
walk 186 ~6.4× ~7.1× 1 / 186
kick 134 ~4.0× ~4.4× 1 / 134

读数要点

  • 抖动在 执行态关节速度 / dof_acc，不是 reference 自带；位置高频仅略升，但逐帧 ‖Δq‖ 与速度 RMS 在抖样本上明显抬高。
  • 现行 filter 不门控平滑度，故上述片段仍进入 VAD_Cleaned_50Hz_Rollouts_V2。
  • 上肢（wave_arms / clap / punch / handshake 等）在同协议抽样中多数接近 reference；问题集中在 locomotion / 踢腿。
  • 接近不抖的稀有样本：walk val:125:1:195:238（walk back，j≈0.73×）；kick val:847:1:210:316（j≈1.24×）。普通前向 walk 中位仍约 6×。
  • 机制工作假设（与 reward 合同一致、待加训验证）：body 跟踪权重大、motion_joint_pos/vel=0、仅弱 action_rate_l2；接触步态下闭环过修表现为高频颤振。action_scale=2.0。

逐条分数：outputs/plan50_bm_tracker_filter/d6_gtrxl_rollouts_v2_jitter_probe/walk_kick_jitter_scores.json。n`，内容同合同）。

5. Analysis

  • Finding: Tracker 侧 D6 GTrXL test BM SR 高于 single-policy baseline（§4.1）；同一执行器按「跑完且未 terminate」得到 VAD_Cleaned_50Hz_Rollouts_V2 接受率 99.4%（§4.2）。§4.3 视频即该合同下的成功采样。§4.5 进一步表明：accepted 不等于 locomotion 平滑。
  • Working interpretation（已确认）: 现行 filter 只保证 可跑完，不保证局部 tracking 质量，也不保证无高频关节颤振。walk/kick 上 exec/ref jerk 中位约 4–6×（§4.5）；上肢同集明显更稳。公开 SONIC 审计（hierarchical rollout tracking audit）另归纳 delay / amplitude / EE 几何问题；本栈 overlay 可平行阅读，但执行器与 SONIC 不同，数字不可直接混表。
  • Unknown: 8 条 reject 未做逐条动力学归因；accepted 集上尚未公布与 SONIC 对齐的 delay / EE 量化表；jerk 门阈值尚未标定。
  • Next（further work）:
  • 在现行 filter 之上加 Tracking MPJPE、EE（腕/踝）与 jerk / accel 阈值或分位数门，再导出更干净的 Rollouts 子集。
  • 训练侧加强调节平滑（action-rate / jerk）并复测 walk/kick 的 exec/ref 比。
  • 针对与本报告同类的 50Hz cleaned rollouts，与 SONIC 在 delay、amplitude、EE trajectory / keypoint 上做 同协议量化对照（不替代各自产品线主指标）。

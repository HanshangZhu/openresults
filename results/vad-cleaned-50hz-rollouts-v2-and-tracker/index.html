UniLab PPO tracker 与 VAD_Cleaned_50Hz_Rollouts_V2 构建

Date/scale: 2026-07-23 / tracker train 1113 · filter 1384/1392 · semantic K=8
Output profile: markdown-project-report（HTML 同目录）
Results profile: training-physical + dataset-verifier
Verdict: PASS

本报告先交代 UniLab–MuJoCo PPO tracker 的训练数据、num_envs=4096 流程与最终 BeyondMimic success rate；再说明如何用该 tracker 产出与 V1 对应的 VAD_Cleaned_50Hz_Rollouts_V2（50Hz 过滤执行态集）。Tracker 细节见 2026-07-23-MOE-unilab-specialist-distill-report.md（未随本公开包发布）。

1. Conclusion

PASS。

  • Decisive evidence: tracker 学生 D6 GTrXL test BM SR 0.993（single-policy baseline 0.960）；用其过滤得到 VAD_Cleaned_50Hz_Rollouts_V2 接受 1384/1392（99.4%）（§4）。
  • Counter-signal: 过滤仍拒 8 条（terminate / 未跑完）；reject live 视频已覆盖全集。
  • Not shown: 可部署动作 router；GTrXL 相对 MLP 的容量优势（MoE 报告标 无证据）；本 filter 尚未用 Tracking MPJPE / EE 二次卡控（MPJPE 仅审计）。
  • Decision: 下游先用 VAD_Cleaned_50Hz_Rollouts_V2；进一步工作见 §5（MPJPE/EE 加严过滤；与 SONIC 在 delay / amplitude / EE 几何上做同协议量化对照）。

5. Analysis

  • Finding: Tracker 侧 D6 GTrXL test BM SR 高于 single-policy baseline（§4.1）；同一执行器按「跑完且未 terminate」得到 VAD_Cleaned_50Hz_Rollouts_V2 接受率 99.4%（§4.2）。§4.3 视频即该合同下的成功采样。
  • Working interpretation（已确认）: 现行 filter 只保证 可跑完，不保证局部 tracking 质量。公开 SONIC 审计（hierarchical rollout tracking audit）在 15 条代表 clip 上归纳：动作越快、连续变化越多，execution 越易出现局部 delay（wave-arms 最明显；kick 上臂晚于腿）；delay 常伴 amplitude 不对称；全身 MPJPE 掩盖腕/踝等 EE / geometry 集中误差；慢动作或部分 walk 视觉上更一致。本栈 overlay 应用同一读法，但执行器与 SONIC 不同，数字不可直接混表。
  • Unknown: 8 条 reject 未做逐条动力学归因；accepted 集上尚未公布与 SONIC 对齐的 delay / EE 量化表。
  • Next（further work）:
  • 在现行 filter 之上加 Tracking MPJPE 与 EE（腕/踝）阈值或分位数门，再导出更干净的 Rollouts 子集。
  • 针对与本报告同类的 50Hz cleaned rollouts，与 SONIC 在 delay、amplitude、EE trajectory / keypoint 上做 同协议量化对照（不替代各自产品线主指标）。

TASK-515 八动作数据集 · 人工审查三处毛病

人工过审 271 片段后挑出的三处毛病，每处给数据集原生片段名与执行回放。数据集自报 physics_processed:false、quality_approved:false：它逐帧标了关节越限 / 自穿插 / 地面穿插，但对关节抖动和整体悬空不设门——下面三处正好落在这两个盲区里。

本页只报人工看到的毛病与片段名，不下「剔除」裁定（审查中三处均记为 pass + note，未剔）。回放为参考轨迹的运动学直渲（reference_qpos → MuJoCo，无物理跟踪器），50fps。

1. cross_arms 抱臂 · 手臂高频跳变（类内普遍）

reason=jitter 片段 cross_arms_0015（train）· 同类 cross_arms_0016 / 0017 同样病。62 帧，源自 AMASS BMLmovi/Subject_79_F_14 帧 65–127。

抱臂时双臂前臂出现逐帧小幅跳变，不是单条坏样本，是抱臂这一类的共性——像是 retarget 在双臂交叠构型下的不稳。几何审计这条抓到的是另一回事：自穿插 62/62 帧、峰值 43.9mm（双臂交叠必然互穿），但审计不报「抖动」。

2. crouch 下蹲 · 膝盖跳变（几何审计全干净却仍抖）

reason=jitter 片段 crouch_0002（dev_val）· 同类 crouch_0000 / 0003–0006 同样病。67 帧，源自 AMASS MPIHDM05/HDM_dg_03-05 帧 1319–1386。

下蹲到底再起身的过程膝关节有可见跳变。这条最能说明审计盲区：自穿插 0、地面穿插峰值 0.6mm、关节越限 0 帧——几何全过，但人眼一眼看到膝盖抖。抖动不在几何审计的量纲里。

3. crouch 下蹲 · 双脚腾空（动力学风险，非抖动）

reason=risk 片段 crouch_0007（dev_val）。39 帧，源自 AMASS MPImosh/50004/simple_crouch 帧 240–279。

唯一一处从「抖动」升级到「动力学风险」的：下蹲相里出现双脚同时离地。地面穿插审计只看穿地（脚在地面以下），看不见悬空（脚在地面以上）——所以这条几何审计地面穿插峰值仅 0.3mm、判干净，实际却是腾空。若后续拿这份数据喂 PHC / tracker，这类离地帧直接影响可执行性，呼应 REPORT 里「训练准备 ≠ 动态可执行」。

小结

  • 三处毛病、两个盲区：抖动（cross_arms 手臂、crouch 膝盖，且 crouch_0002 几何全干净）与悬空（crouch_0007 双脚腾空，被地面穿插审计漏看）。
  • 其中两处是类内系统性（cross_arms 全类手臂跳变、crouch 多条膝盖跳变），不是个别坏样本，指向 retarget 管线在这两类构型上的共性。
  • 与数据集自报 quality_approved:false 一致：几何审计覆盖穿插 / 越限，抖动与悬空需人眼补门。三处均未剔除，仅记录。

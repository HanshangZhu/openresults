G1 动作段判定器 — 每动作一个模型,在冻结测试集上的八类评测

Preliminary。八个动作各训一个判定模型(同一套合成增广配方,互不共享参数),在一批 标注前就抽定、从未进入训练的测试段上逐类评测。回答两件事:这条路线现在能覆盖哪些动作, 以及不能覆盖的那些是怎么坏的。

Conclusion

MARGINAL(八类里 1 类可直接用,2 类单侧可用,3 类判反)

  • crouch 可直接用:准确率 0.950(全拒基线 0.700),precision 1.000、recall 0.929、 负类 recall 1.000——判脏的 13 段全对,6 段干净一段没冤枉(主表)。
  • kick / walk 单侧可用:recall 均为 1.000,脏一段不漏;但负类 recall 只有 0.200 / 0.000, 干净段几乎全被误拒,拿去清洗数据会把可用数据一起丢掉。
  • clap / punch / wave_arms 判反:准确率低于全拒基线,precision 与 recall 同时低。 这三类的脏段时长中位数显著大于干净段(clap 10.6 s 对 3.6 s),而合成增广恰好教了 "比原样长 = 脏",两者共现(Analysis);因果归属 待验证。
  • 每动作一个模型明显优于八类合一:同一批 kick 测试段,单类 recall 1.000、合一 0.600。

Problem and terminology

研究问题:给定一段动作和它声称的动作类别,判定这段是否只含该动作、不含前后动作残留或 其他污染。本报告问的是:每个动作各训一个模型,在从未参与训练的测试段上分别做到什么水平。

Term 本报告 operational definition Scope / not to confuse with
判定模型 冻结的连续编码器 + 6 层双向 Transformer(10.9 M 参数),输出逐 0.2 s 污染概率与整段污染概率;任一 ≥ 0.5 即判"拒" 架构与增广细节见前一篇的公开页
每动作一个模型 八个动作各自训练一个模型,参数不共享;每个模型只在自己那一类上使用 与"八类合一"(一个模型带类别条件覆盖八类)相对
合成增广 四种构造,全部在同一条原始录音内部取材:起点前移、终点后移、跨类冒充、部位替换。判净的段既是正样本,又是这四种的原料 训练数据里没有任何人工细粒度标注,纯合成
冻结测试集 2026-08-16 按用户指令抽定的 8 类 × 20 段,抽样池 = V3 清单中 unreviewed 的段;抽定后排除于一切训练材料(脚本启动时断言),标注在独立库进行且界面关闭模型面板 与训练标注队列是两个库、两个界面
walk 的考卷 冻结测试集的 walk 20 段至今未标注,故用 round-1 批次的 19 段替代——同样从 unreviewed 池随机抽、同样零接触训练 抽样方法与冻结测试集一致,可与其他类横向比较
准确率 / precision / recall / 负类 recall 以"脏"为正类:准确率 = 判对比例↑;precision = 判拒的段里真脏的比例↑;recall = 真脏的段被拒的比例↑;负类 recall = 真干净的段被留的比例↑ 四个必须一起看
全拒基线 把所有段都判脏的常数判定器的准确率 = 测试段中脏的占比;模型准确率超出它的部分才是判别贡献 不是模型
区间命中 人工标注写明了污染时间区间的脏段中,模型过线区与该区间有重叠的比例 段级判对不等于位置指对

Analysis

  • 测量:八类里只有 crouch 三项指标同时达标(主表);kick 与 walk 的 recall 为 1.000 而 负类 recall 为 0.200 / 0.000,说明模型把判定线画得过严,不是分不出而是不敢留。
  • 测量:clap / punch / wave_arms 准确率低于全拒基线,且这三类的脏段时长中位数明显大于 干净段(clap 10.6 s 对 3.6 s、wave_arms 11.9 s 对 7.8 s)。合成增广的三种形式 (起点前移、终点后移、部位替换)都会让样本变长同时标脏。二者共现,待验证。
  • 测量:段级判对与位置指对是两回事。handshake 准确率 0.700 但区间命中 0/8;kick 区间 命中 7/8 为全类最好。
  • next:逐类调阈(recall 已达 1.000 的类,负类 recall 有回收空间);改增广使脏样本与 干净样本等长,再看判反的三类是否翻正;补标冻结测试集剩余 27 段与 walk 的 20 段。

诊断量(非正式指标)

用一个与阈值无关的排序读数(随机取一脏一净、脏的分数更高的概率)做过两项诊断,仅用于 判断"判别力不足"还是"阈值站错位置",不作为本报告的判定指标:

  • 该读数在 crouch 为 1.000、kick 0.900、walk 0.850,而 clap 0.389、punch 0.369、 wave_arms 0.292——低于 0.5 表示排序系统性反了。
  • 同一读数若只用"段长"排序:kick 0.750、clap 0.722、wave_arms 0.655,在 clap、 wave_arms、cross_arms、punch 四类上高于模型自身。这是把时长列为混淆变量的依据。

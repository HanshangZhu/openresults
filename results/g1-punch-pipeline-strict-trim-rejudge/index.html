Method

流水线三步(伪代码级):

  1. 逐 0.2 s 窗打分;全窗 < 0.70 → 原样入池
  2. 有窗过线且全部过线窗在段首 1.0 s 内 → 裁头至最末过线窗端点 + 0.3 s(裁后须 ≥1.5 s) → 裁后重打分;过 → 裁后形态入池
  3. 其余(报警在段中/段尾/超长/裁后仍报警)→ 拒

Analysis

  • 测量:双赢的机制是"最严档的冤杀集中在段首"——阈值收严后被拒的净段多因段首误报, 裁头重判给了它们第二次机会;真头部残留段同样借此以干净形态回池。两侧回流都提高留存, 且回流段的混脏率极低(3 种子均只混入 1 段),纯度同步上升。
  • 测量:起势损失从无条件裁头的"全部净段"限缩到"入池净段的约 16%";彻底归零的唯一路径 是段首报警精度继续涨(= 标注,报警端点的监督已在现行区间标注内)。
  • 判据 v3 使 R 从达标约束转为产出量参数;punch 的 R 增长通道(标注学习曲线 +0.05~0.06/翻倍)依然有效,不达标压力消失后可按下游需求决定是否继续投标注。

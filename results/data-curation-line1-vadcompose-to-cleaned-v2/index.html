线 1：VADCompose → Cleaned V2 —— 人工审核怎么筛

原始数据是 VADCompose release 的 val.pkl（1993 条长录音，20 fps G1 动作 + 逐段动作标注 frame_ann）。这条线把长录音切成单动作短段、人工逐段审核，产出 Cleaned V2 good set：1446 段（quality_tier：strong 1434 · borderline_low_v 12）。

1 · 筛选流程

① 候选定义：frame_ann 的逐段标注切段；85 个原始（raw）动作标签 归并到 9 个 parent 类（如 "walk forward"/"low walk" → walk；"applaud" → clap）。
② 人工审核：review_app 前端逐段看渲染视频，判 pass / fail / edit（改标签）/ trim（裁边界）。 审的是：动作纯度（段内只有这一个动作）、边界是否切准、动作是否符合标签语义、质量是否离群。
③ 提名机制：不是每段都被审——punch 用 validity 分类器排序后按优先级提名复核 （994 候选只收 161 的原因）；walk 开过专场（显式 fail 32 条几乎全在 walk）。
④ 记录：判定入 sqlite（可追溯）；显式 fail 未记录文字原因——判断依据是视频本身。

教学要点：被删的两种性质要分清——"显式 fail" 是人看过说不行； "未收录" 是从未通过提名/审核（包括根本没被提名的）。下面每个动作的被删侧混有两种，卡片上有标注。 看视频时问自己：这段为什么进不了训练集？（常见答案：动作混杂、边界切进了相邻动作、 幅度/姿态离群、和标签语义不符。）

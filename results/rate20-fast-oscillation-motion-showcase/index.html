Preliminary：池内快振荡上肢动作 rate20 × 五 tracker

Status: preliminary · Date: 2026-07-30
范围：本页完整陈列测量结果（视频、曲线、指标）， 不做解读或判定——results are left as is；结论另行成文。

数据筛选

在 VADCompose V2 release 全量（train + val 共 11,946 条已重定向 G1 序列，约 79 小时，20 fps）上， 用 4 秒滑窗扫描骨盆局部坐标系下的双腕轨迹，按自相关主周期和逐周期幅度标出持续振荡的时间窗。 只保留满足三个条件的窗口：至少 3 个完整周期、逐周期幅度不低于 0.15 m、且窗口落在已人工审核的 参考池片段内部；动作类 walk 与 kick 整类排除。每个片段取其中最快的一个窗口，按主频从高到低取前 20 条（1.67–2.22 Hz；类别构成 punch 9、wave_arms 7、handshake 3、cross_arms 1），评分与展示窗口直接对准标出的振荡段。

held lookahead 与 native lookahead 的区别

GMT (native) 每个控制步读取当前到未来 0.9 秒内的 10 个参考采样点，GMT (held) 用完全相同的 模型权重、但把未来 9 个槽位全部替换成当前帧——两臂只差"未来参考输入"这一项。

指标口径与怎么看

  • 腕幅度保留率 = 执行 ÷ 参考的逐周期腕幅度（骨盆局部系双腕，autocorr 找主周期 → 逐周期 3D 包围盒跨度 → 周期均值），打分窗内。目标 1.0；<1 为幅度缩小，>1 为放大。
  • link 误差 = 骨盆局部系 9 个共同 link 的位置误差均值（m，↓），打分窗内。
  • 主频 exec/ref = 执行与参考各自窗内 autocorr 主频（Hz）；窗内找不到合格 自相关峰的记 —（2 s 窗只含约 3.5–4.5 个周期，波形不干净时测不出）。
  • 视频五格并排，顺序 GMT (native) / GMT (held) / TWIST / SONIC / D6；每格中机器人本体 = 该 tracker 的物理执行，蓝色半透明 ghost = 参考动作，同一时刻同一相机， 蓝色露出来的部分就是执行没跟上的部分。
仪器门禁（机械容差检查，逐项实测值）： 参考扩展重叠一致性 位置 1.19e-07 m（容差 1e-6）/ 速度 7.99e-06 m/s（容差 5e-5）；格式转换往返 关节角 0.000e+00 rad / 几何 0.000e+00 m； 幅度尺子两条实现路径最大相对差 0.1967%（阈 2%）。打分窗全部落在扫描标定的振荡段上。

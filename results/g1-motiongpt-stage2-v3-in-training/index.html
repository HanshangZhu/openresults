G1 MotionGPT Stage 2 — 把 VADCompose V3 加入训练数据后的动作命名与污染判别

Preliminary。第二阶段（动作-语言模型）先只用 BABEL 训练、再把 VADCompose V3 的干净段加入训练， 本报告记录两轮的观测、两个测量缺陷的修复，以及能与不能证明的结论。第二轮训练已跑完 60,000 步。

Conclusion

FAIL（留出集判别 AUC 未达靶子；训练已完成，数字为终值）

  • 决定性证据在完全留出的 V3 train split：判别 AUC 为 0.477（n_extra）与 0.526（nominal_surprisal），均低于手工特征基线 0.615（主表）。同一集合上脏段叫出标称动作的比例 0.370 反而高于干净段 0.324，方向与假设相反。
  • 一个容易误读的数：V3 val 上 nominal_surprisal 的 AUC 是 0.706，超过靶子——但该集合 1,559 个干净段中有 1,248 个进过训练，这个数由记忆产生，不成立。
  • 加入 V3 确实带来了目标域的命名能力：留出的 V3 val 干净段上命名率 62.7%，多数类基线 16.7%；只用 BABEL 训练时模型把握手说成 arm movements、把抱臂说成 touching body part。但该能力不跨 split 迁移（0.627 → 0.324），也不携带污染信息。
  • 不能证明"动作-语言模型对污染无效"：只证明生成动作名这一类读数（叫出标称动作、多叫了几个、标称动作的负对数似然）在本设置下不携带污染信息。

Problem and terminology

研究问题：一个在 G1 空间自训的动作-语言模型，能否通过"说出这一段里有哪些动作"来判别 VADCompose 片段是否被污染？

与轮 1 的差异

唯一有意的差异是训练数据：轮 1 只有 BABEL 窗口，轮 2 增加 V3 val clean 段（v3_frac=0.35）并给它专属提示词 "Name the single action performed: "。另有两处测量侧修复（见 Analysis），它们改变的是读数不是模型。

Analysis

  • 加入 V3 使模型获得了目标域的命名能力（V3 val 留出 62.7% vs 多数类 16.7%）。工作解释：BABEL 的 act_cat 体系里没有 handshake 类目、cross_arms 对应的是 crossing limbs，模型只用 BABEL 训练时说的是 arm movements 这类不指向动作身份的词。此解释来自轮 1 生成文本的直接观察，非单因素隔离实验。
  • 该能力不跨 split 迁移：同一 checkpoint 在 V3 val 留出上 62.7%、在 V3 train 留出上 32.4%（主表）。手工特征基线在同一协议下也从 0.747 掉到 0.615，两条线都在同一处掉，待验证 是分布差异还是两轮审查的标注口径差异。
  • 命名能力与污染判别脱钩，且留出集上方向相反（脏 0.370 > 干净 0.324）。这说明污染段中的第二个动作没有进入生成结果，不是模型认错了标称动作。为什么没有进入，本轮无法回答（待验证）。
  • 两个测量缺陷已修复，都曾把正确预测判成错误：解码在序列吐出 EOS 后继续生成，"wave arms" 被写成 "wave armse"，字符串匹配随即失败（同一 checkpoint 命名率 0.148 → 0.602）；BABEL 窗口 F1 的验证生成只有 32 个样本，标准误约 ±0.08，盖住全部观测差异，且仅比"永远输出 walk/stand/transition"的常数基线（F1 0.202）高 0.047。
  • 下一步不追加训练预算。理由是 28,000 步之后 32,000 步的训练没有改变任何 V3 读数，判别 AUC 全程在 0.497–0.514。改为设计不依赖"生成动作名"的读数（待验证）。
Appendix — 头条数字代入式

named_nominal = 0.324（V3 train 留出）：645 个 clean 段中，m2t 生成文本解析出的动作父类集合包含该段 action_parent 的有 209 个；209 / 645 = 0.3240。脏段为 417 / 1,127 = 0.3700。

多数类基线 = 0.082（V3 train 留出）：645 个 clean 段中最高频的 action_parent 是 wave_arms，53 / 645 = 0.0822。V3 val 留出集上该值为 cross_arms 52 / 311 = 0.1672。

判别 AUC = 0.526（nominal_surprisal，V3 train 留出）：以 dirty 为正类、clean 为负类排秩（平局取平均秩）， AUC = (R_pos − n_pos(n_pos+1)/2) / (n_pos · n_neg)，n_pos = 1,127，n_neg = 645。 直接两两比较 P(dirty > clean) = 0.5259，与秩公式一致，零平局。

为什么 surprisal 中位数差 18 倍却几乎不分离：两组都是双峰。四分之一以上的段 surprisal 恰好为 0 （模型完全确定），而上四分位几乎重合（clean p75 6.295 / dirty 6.214，p90 8.673 / 8.283）。 中位数落在分布的陡坡上，clean 在零点多一点质量就足以把中位数从 2.711 拉到 0.152，秩序关系却没变。

手工特征基线 0.615：extra_trees 在 V3 val（1,559 clean / 1,313 dirty）上训练，在 V3 train（645 clean / 1,127 dirty）上测。95% 纯度阈值下 extra_trees 无可行操作点，logistic 仅保留 2 段。

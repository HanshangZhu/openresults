BABEL→G1 八类参考池：构建流程与全量人工审查

Status: dataset · Date: 2026-08-01
范围：本页只报告做了什么（构建步骤、数量、逐段人工审查的 pass/fail 对照示例）， 不做机理解读；分析另行成文于研究仓库。

做了什么

从本机 AMASS 原始 SMPL-X 压缩包出发，构建一个 8 类、原生 50 Hz、逐段人工审查过的 Unitree G1 纯运动学参考池（无任何物理执行字段）。七个步骤：

  • 重定向：17 个 AMASS 包共 13,258 条 raw SMPL-X，经 GMR（打帧率补丁， 原生帧率一步重采到 50 Hz）重定向到 G1，得 13,020 条母序列（40.2 小时）；抽 120 条做源率反查， 全部确认真 50 Hz 而非插值。
  • 标注对齐：BABEL 帧级标注与母序列连接（8,652 条接上），时间基不一致的 序列按帧率比例换算，换算不可靠的 227 条整条排除。
  • 切段：标注区间映射到 8 个动作类（walk / kick / crouch / punch / clap / wave_arms / cross_arms / handshake），端点裁 transition，最短 0.4 s，同文本相邻合并。
  • 重叠标注处理：同一时间窗被多条标注覆盖时，按一张 180 对 （动作类 × 重叠标注文本）的判定表处理——判"同一动作的第二条描述"保留，判"真并发第二动作" 把覆盖帧裁掉；判定表由 5 次独立 LLM 分类多数票产生，投票分裂的 29 对由人工看视频裁定。
  • 自动门禁：肘/腕关节贴限超过 50% 时长的段（IK 撞限）、整段两掌从未靠近的 clap（重定向丢失接触）、完全相同时间窗的重复段，全部剔除。
  • 人工审查：除 walk 外 7 类全量 + walk 前 250 段，逐段观看回放； fail = 风险过高剔除，剔除原因（重定向错误 / 动力学风险 / 内容不符）记录在审查库。
  • 产出：审查后保留 909 段 / 35.0 分钟；schema、正解运动学 往返、时长对齐三道机器验证 0 failures。

数据来源与说明

动作标注来自 BABEL（Punnakkal et al., CVPR 2021）， 人体动作数据来自 AMASS（Mahmood et al., ICCV 2019）， 均按其学术许可使用。本页视频全部为 Unitree G1 机器人模型的运动学回放渲染（衍生可视化）， 不包含也不再分发任何原始人体数据。数据集本体、审查库与逐段剔除记录保存在研究仓库， 不随本页公开。

4. 附加抖动与授权

末端高频抖动 JITTER-EE-HF-WELCH-V1（世界系，8–25 赫兹 Welch 带内均方根，毫米；定义见 docs/eval_standard/jitter_ee_hf_extra_metric.md）。三臂残差对抖动几乎无影响（残差−零残差 中位 +0.06 / −0.03 / +0.05 毫米），符合 V7 无平滑项，且没把抖做坏。GMT 裸执行本身的抖仍在（踢腿零残差 1.17 毫米，远高于参考 0.37）。

授权探针（踢腿 16 单元）：GMT 指令的高频抖（末端等效 23.5 毫米）远大于执行（1.5 毫米），执行/指令 = 0.07——物理把指令高频低通掉 93%。抖起源于指令通道，残差名义碰得着，但物理同样衰减残差的高频修正 7 倍，残差也无法在 50 赫兹预测并反相抵消 GMT 的 8–25 赫兹抖。故残差修不动 GMT 的底噪抖；频域项只能保证「残差自己不加抖」。

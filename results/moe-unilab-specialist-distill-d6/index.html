本报告是 BeyondMimic 合同下 specialist → DAgger 蒸馏 主线的 PPO 版复跑与升级。上一版同合同、fastSAC 管线（2026-07-22-beyondmimic-retrain-experiment-summary.md（未随本公开包发布））学生 test 峰值约 0.843；本版改用 PPO tracker，在有限迭代预算下再验 specialist / 蒸馏叙事。完整流水线见 §3 Experimental setup。

1. Conclusion

PASS。

  • Decisive evidence: PPO 下 locked Spec oracle 与 best-by-val 学生 val BM SR = 0.994；test 上学生高于同协议 single-policy G = 0.960（D6 GTrXL 0.993 / D8 MLP 0.977），并远高于上一版 fastSAC 学生峰值 0.843（主表）。
  • Counter-signal: specialist 过训有灾难性遗忘风险（clap Spec_final@3998 → SR 0；须按 val 锁早 ckpt）；末轮 D9 相对峰值略降。D6 用于 50Hz physical filter 时，accepted walk/kick 相对 reference 普遍高频关节颤振（§5.4），上肢更稳；BM SR 不刻画该平滑度。
  • Not shown: GTrXL 容量优于 MLP（本实验无支持该 claim 的证据，见 §5.3 / Analysis）；可部署 router；与 fastSAC 版完全同超参的严格 A/B；本报告主表未把门控 jerk。
  • Decision: 有限预算下继续采用 PPO + specialist（难动作）+ DAgger 保留；架构选择不因本表主张 Transformer 必胜；若下游消费执行态，须另加平滑 / MPJPE 合同。

2. Problem and terminology

本报告检验三条命题（semantic K=8、BeyondMimic full-motion SR）：

  1. 算法代际： 将 tracker 从 fastSAC 换为 PPO 后，单网与蒸馏学生的宏 SR 是否明显高于上一版峰值（~0.84）。
  2. Specialist（有限预算）： 在有限续训量上，难动作（如 kick）上 specialist 是否优于 matched-iter single-policy baseline（G）；同时是否存在易动作上的灾难性遗忘，因而必须按 val 选 ckpt。
  3. 蒸馏保留： DAgger 得到的单一学生能否最大程度保留 specialist 收益，并在 val/test 上优于 G。

3. Experimental setup

整条实验按固定顺序推进：single-policy → specialists → 选模锁定 → DAgger 蒸馏 → 终局对照。Tracker 一律为 UniLab–MuJoCo PPO（相对上一版 fastSAC）；切分方式为 semantic K=8；主指标为 BeyondMimic full-motion SR。

3.2 端到端流水线

  1. Train single-policy（G0）
    在全部 train clips 上训一台 PPO；num_envs=4096。本树取检查点 @1999 记为 G0（Spec 的共同 resume 起点）。

  2. 续训 matched-iter single-policy（G）∥ 训 8× specialists（Spec）
    - G：自 G0 在全量 train 上继续 PPO，取与 Spec 对齐的预算终点 @4000（主对照；旁路曾续到 ~8000，不作主表）。
    - Spec：按 semantic cluster 各开一条 run，自 G0@1999 resume，每条再 +2000 iter（至约 @3998/3999），save_interval=500，PARALLEL=8，每进程同样 num_envs=4096。

  3. Phase A — 对照评测
    每 cluster 在 val+test 上评 G0 / G / Spec_final（rollouts=4）；并对 Spec@2000…3500 做 val 扫，供选模。

  4. Phase B — 锁定老师（teachers.lock）
    - clap（c0）：强制 Spec@2000（防后期遗忘崩溃）。
    - 其余 cluster：在 Spec@2000…3500 上 argmax val BM SR（平手取更低 MPJPE）。
    - 组合评测时用已知 cluster 标签选对应 locked Spec → specialist oracle（评测上界，非默认可部署单网）。

  5. Phase C — DAgger 蒸馏 ×10
    - 标签始终 = locked Spec（不在线改 PPO teacher）。
    - 学生同时训 MLP + GTrXL（SKIP_MLP=0）。
    - Round 0 由 G@4000 驱动采集；Round ≥1 由上一轮 GTrXL 学生驱动。
    - 每轮结束后对该轮学生做 val ×4 BM eval，得到 D0…D9。

  6. Phase D — 终局对照
    按 val 选 best 学生（本报告：D8 MLP、D6 GTrXL）并含末轮 D9；与 G0 / G / locked Spec oracle 一并做 val+test ×4。主数字见 §5。

  7. （附加）Frozen SONIC 对照
    同一 val/test clip 集上跑 frozen GEAR-SONIC bare，再后验套 BM SR，与 D6 GTrXL 并列（§5.4）；不改变上述训练流水线。

full-train PPO (num_envs=4096) → G0@1999
        ├─ continue full-train → G@4000          (matched-iter baseline)
        └─ 8× cluster resume +2000 → Spec_*     (specialists)
              → Phase A/B eval + teachers.lock
              → Phase C DAgger×10 (MLP+GTrXL; R0=G@4000)
              → Phase D final val+test×4

6. Analysis

  • Finding: PPO 代际下，宏 SR 与难动作（kick）均相对上一版 fastSAC 峰值大幅抬升；best-by-val 学生贴齐 locked Spec oracle，并优于 G（§5.1–5.2）。另：D6 的 BM SR 高 与 walk/kick 执行平滑 可分离——accepted locomotion 仍可相对 reference 颤振数倍（§5.4）。
  • Working interpretation（已确认）: 有限训练量上 specialist 在难动作上优于 single-policy；过训有灾难性遗忘风险，故必须 val 选模；DAgger 能最大保留 specialist 收益，使可部署单网优于 G。SR 合同不约束高频关节颤振；body 跟踪主导、关节项为 0、弱 action-rate 时，接触步态更易过修。
  • Architecture claim: 无证据证明 GTrXL > MLP（§5.3）；val 多数轮次 MLP ≥ GTrXL，唯一同轮 test（D9）亦为 MLP 略高。
  • Next: 本线 PPO MoE 数字已齐；若衔接 50Hz DP / cleaned rollouts，应并行加 jerk（或 accel）门与/或训练平滑项；router / 部署待指定。
